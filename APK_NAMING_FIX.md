# Исправление несоответствия в именовании APK файлов

## Проблема

В workflow файле `.github/workflows/stable-build.yml` было обнаружено несоответствие в именовании APK файлов:

### Создавался файл:
```
FinancialSuccess-v${VERSION}-${DATE}.apk
```

### Но проверялся файл:
```
FinancialSuccess-v${VERSION}-${DATE}-debug.apk
```

Это приводило к ошибкам при проверке наличия APK файлов в workflow.

## Причина

В процессе разработки workflow были добавлены ссылки на APK файлы с суффиксом `-debug`, но при копировании файла суффикс не добавлялся.

## Исправления

### 1. Удален суффикс `-debug` из всех ссылок на APK файлы

**Измененные места:**
- Строка 553: Проверка наличия APK в секции `screenshots-phone`
- Строка 564: Получение размера APK в секции `screenshots-phone`
- Строка 567: Установка APK в секции `screenshots-phone`
- Строка 903: Проверка наличия APK в секции `screenshots-tablet`
- Строка 914: Получение размера APK в секции `screenshots-tablet`
- Строка 917: Установка APK в секции `screenshots-tablet`
- Строка 1060: Вывод информации об APK в секции `Build Summary`

### 2. Исправлен путь к исходному файлу

**Изменение:**
- Строка 269: `app.apk` → `app-debug.apk`

## Результат

Теперь все ссылки на APK файлы используют единообразное именование:
```
FinancialSuccess-v${VERSION}-${DATE}.apk
```

## Тестирование

После применения исправлений workflow должен:
1. ✅ Создавать APK файл с правильным именем
2. ✅ Находить APK файл при проверке
3. ✅ Успешно устанавливать APK на эмулятор
4. ✅ Корректно отображать информацию о файле
