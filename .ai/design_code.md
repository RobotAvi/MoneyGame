# Дизайн-код приложения (app-wide)

Единые правила дизайна для всех экранов: основы, цвета/темы, типографика, элементы интерфейса, а также требования к ключевым экранам и всплывающим меню.

## 1. Базовые принципы
- Material 3 (M3). Единый компонентный подход, без legacy-виджетов.
- Day/Night тема. Контраст — не ниже WCAG AA. Поддержка Dynamic Color (Android 12+) при наличии.
- Единая палитра через theme tokens (colorPrimary/OnPrimary, Surface/OnSurface и т.д.). Цвета — через тему, не прямые hex в разметке.
- Адаптивность: min touch 44×44dp, sp/ dp, поддержка масштабирования шрифтов.
- Единый фон: градиент `bg_app_gradient` (+ night). Поверх — стеклянные/поверхностные карточки (`bg_glass_card` или M3 Surface).

## 2. Типографика
- Базовый шрифт: Inter/Roboto Flex (вариативный), веса 400/600/700.
- Размеры: заголовки 20–32sp, контент 14–16sp, подписи 12–14sp.
- Нет заглавных ALL CAPS, кроме системных кнопок где уместно. Текстовые стили — через TextAppearance M3.

## 3. Иконки и изображения
- Векторные иконки 24dp, монохром, единый стиль. Цвет — через tint из темы.
- Иллюстрации WebP ≥1080px, без фона; lazy-loading где возможно.

## 4. Карточки и стекло
- Карточки — MaterialCardView, радиус 12–20dp, elevation 4–10dp.
- Стеклянные подложки для блоков/хедеров — `bg_glass_card`/поверхностные цвета темы.

## 5. Навигация и анимации
- Анимации лёгкие, 120–250мс. Без навязчивых всплывающих подсказок.
- Lottie: допустимо для микроанимаций (кубик, выбор дня).
- Жесты (swipe) там, где ожидаемо (календарь месяц назад/вперёд).

## 6. Доступность
- Контент-описания у интерактивных элементов, озвучиваемые состояния.
- Контраст текста с фоном — AA (проверка на светлой/тёмной теме).
- Фокус/состояния — визуально различимы.

## 7. Экраны

### 7.1. Основное меню (Main)
- Фон: `bg_app_gradient` + при необходимости приглушённый бэкграунд-имидж (overlay), текст — белый/OnPrimary.
- Заголовок приложения — не показывать в тулбаре. Ключевой слоган/название — крупно (32sp) в центре.
- Две CTA-кнопки (начать/правила) — стиль M3, 48–56dp высота, контрастный текст.
- Анимация появления: лёгкая, не мешающая доступности.

### 7.2. Все шаги (мастер создания)
- Единый фон, карточки для полей ввода.
- TextInputLayout M3 (outlined), подсказки и ошибки в стиле темы.
- Кнопки навигации шага — фиксированы и заметны, размеры 48–56dp.

### 7.3. Экран «Начинаем» (первый запуск/подтверждение)
- Информативный экран с краткими тезисами (3–5 пунктов), визуальная поддержка (иконки).
- Единый CTA «Начать игру» — акцентный.

### 7.4. Игровой экран
- Верхняя панель без названия приложения.
- Календарь 7×4, текущая неделя — во второй строке, ячейки ≥64dp, число 16–18sp.
- Под календарём — панель событий вместо модалок. Заголовок 18sp, текст 14–16sp, 1–2 кнопки.
- Нижняя панель действий — карточка с 4 круглыми кнопками единого вида.
- Звуки и лёгкие анимации — допускаются.

### 7.5. Всплывающие меню и окна
- Везде, где возможно — вместо блокирующих AlertDialog использовать инлайн-панель/буттом-шит.
- Системные диалоги остаются только для редких подтверждений/финала.
- Единый стиль: M3, контрастный текст, крупные кнопки.

---

## 8. Поведение
- Без лишних тостов и всплывающих уведомлений.
- Состояние событий/панели — единообразное, предсказуемое.
- Обработка тёмной темы — для всех экранов (night-ресурсы).

## 9. Качество и тесты
- UI-тесты для критичных сценариев (бросок кубика, панель событий, навигация календаря, завершение игры).
- Перфоманс: плавные скроллы, отсутствие layout jank.
