# Дизайн-код приложения (app-wide)

Единые правила дизайна для всех экранов: основы, цвета/темы, типографика, элементы интерфейса, а также требования к ключевым экранам и всплывающим меню.


***

## 1. Общий стиль и визуальные принципы

- [ ] Используется единая дизайн-система и компонентный подход (Material Design 3 или аналог).
- [ ] Везде один «дорогой» фон: градиент или light glassmorphism.
- [ ] Карточки: полупрозрачные, с мягкой тенью, скруглением, минимализм.
- [ ] Цвета, шрифты, размеры — через тему, не хардкодом.
- [ ] Акцентные цвета поддерживаются как в светлой, так и в темной теме.

## 2. Адаптивность и доступность

- [ ] Минимальный размер интерактивных элементов — 44×44 dp.
- [ ] Текст масштабируется (sp), layout — в dp.
- [ ] Контраст текста и фоновых элементов соответствует WCAG AA (или выше).
- [ ] У каждого интерактивного элемента есть описания для скринридера (contentDescription).
- [ ] Поддержка Night mode, динамические цвета Android 12+.

## 3. Типографика

- [ ] Основной шрифт — премиум (например, Inter, Roboto Flex), разные веса.
- [ ] Четкая текстовая иерархия: заголовки, подзаголовки, обычный текст, подписи.
- [ ] Размер текста: заголовки 20–32 sp, основной — 14–16 sp, мелкий — 12–14 sp.
- [ ] Нет навязчивого ALL CAPS, кроме редких случаев (CTA).

## 4. Иконки и изображения

- [ ] Векторные иконки (24 dp), единый стиль, цвет — tint из темы.
- [ ] Иллюстрации/фото — WebP, прозрачный фон, разрешение ≥ 1080 px.
- [ ] Lazy-loading (ленивое) изображений.

## 5. Карточки и блоки

- [ ] Карточки — MaterialCardView или glassmorphism, скругление 12–20 dp, elevation (тень) 4–10 dp.
- [ ] Разделение на блоки чёткое, визуально приятно.

## 6. Анимации и переходы

- [ ] Микроанимации (highlight, fade, ripple, масштабирование) — плавные, до 250 мс.
- [ ] Lottie-анимации используются для небольших эффектов (например, бросок кубика).
- [ ] Переходы между состояниями — MotionLayout или Compose Animation, плавные.
- [ ] Всплывающие окна заменены на bottom sheet/inline panel при необходимости.

## 7. Навигация

- [ ] Нижняя панель действий — единый стиль, все кнопки крупные (56 dp круг, 24 dp иконка).
- [ ] Навигация интуитивна, без лишних шагов и pop-up.
- [ ] Жесты swipe там, где ожидает пользователь.

## 8. Панели и меню

- [ ] Всплывающие окна не перекрывают весь экран, скорее bottom sheet или встроенная панель.
- [ ] Системные диалоги применяются только при необходимости (например, подтверждение выхода).
- [ ] Вся дополнительная информация или выбор — в inline EventView под основной областью, не блокирующая UX.

## 9. Структура и качество

- [ ] Проверка перфоманса UI: нет рывков при прокрутке и переключениях.
- [ ] Работает быстро на всех актуальных устройствах.
- [ ] Тесты на ключевые сценарии (основные экраны, действия, панель событий).
- [ ] Однородность — все экраны выглядят и ощущаются частью одного премиум-приложения.
