# Дизайн-код приложения

## 1. Цвет и темы
- Material3 DayNight, поддержка Dynamic Color (Android 12+) при наличии.
- Светлая: `bg_app_gradient` #0D47A1→#42A5F5; Тёмная: `bg_app_gradient`-night тёмно-синий.
- Текст: `text_primary`/`text_secondary` с оверрайдами в `values-night`.

## 2. Типографика
- Основной шрифт: Inter/Roboto Flex (вариативный), веса 400/700, размеры: заголовки 20–32sp, текст 14–16sp.
- Использовать sp, не фиксировать высоты — поддержка масштабирования.

## 3. Карточки и стекло
- Карточки — MaterialCardView, r=12–20dp, elevation 4–10dp.
- Стеклянные подложки: `bg_glass_card.xml`.

## 4. Календарь
- Формат 7×4, текущая неделя — во второй строке.
- Ячейка: число 16sp, индикатор типа слева 4dp, иконка скрывается на текущем дне (виден токен).
- Выделение: вторая строка — утолщённая рамка; текущий/выбранный день — ещё толще.
- Заголовок месяца: светлая подложка `bg_header_chip`, чёткий текст.

## 5. Панель событий (вместо диалогов)
- Заголовок 18sp, текст 14–16sp, кнопки M3 48–56dp.
- Плавный fade или MotionLayout-переход, без блокирующих окон.

## 6. Навигация и анимации
- Свайп между месяцами, стрелки prev/next.
- Кубик: Lottie-анимация, звук броска.
- Микроанимации фокуса (Lottie) — по возможности.

## 7. Доступность
- Контраст WCAG AA+ (ночь/день), описания для скринридера.
- Touch-таргеты ≥44×44dp.

## 8. Иконки
- Vector 24dp, единый стиль, монохром; цвет — через theme tint.

## 9. Тесты и качество
- UI-тесты сценариев: бросок кубика, отображение панели, навигация календаря.
- Отказ от лишних тостов/диалогов в пользу ненавязчивых инлайновых уведомлений.
