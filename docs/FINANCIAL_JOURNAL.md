# 📊 Журнал финансов - Документация

> Система финансового журнала и эта документация регулярно обновляются и соответствуют текущей версии игры.

## 🎯 Обзор

Журнал финансов - это комплексная система отслеживания всех финансовых операций в игре "Финансовый успех". Каждая транзакция автоматически записывается с детальной информацией.

## ✨ Основные возможности

### 📝 Автоматическое логирование
- **Каждый ход игры** = новые записи в журнале
- **Все доходы и расходы** автоматически записываются
- **Детальная информация** о каждой операции

### 📊 Статистика и аналитика
- **Общие доходы и расходы**
- **Разбивка по категориям**
- **Месячная статистика**
- **Тренды и анализ**

### 📤 Экспорт данных
- **Экспорт в TXT формат** для анализа вне игры
- **Возможность поделиться** журналом с друзьями
- **Сохранение для личных записей**

## 🚀 Как использовать

### Открытие журнала
1. В игре нажмите кнопку **"📊 Журнал финансов"**
2. Откроется диалог с полной информацией
3. Просматривайте записи и статистику

### Просмотр статистики
В верхней части журнала отображается:
- 📊 **Общая статистика** по последним операциям
- ➕ **Все доходы** за период
- ➖ **Все расходы** за период  
- 💰 **Чистый результат** (доходы минус расходы)
- 📈 **Всего записей** в журнале

### Экспорт в TXT
1. В журнале нажмите кнопку **"📤 Экспорт в TXT"**
2. Выберите приложение для отправки (WhatsApp, Email, Notes и т.д.)
3. Получите полный отчет в текстовом формате

### Аналитика по категориям
Нажмите кнопку **"📈 Аналитика"** для получения:
- 📊 **Разбивки по категориям** доходов и расходов
- 📅 **Месячной статистики**
- 💡 **Инсайтов** по финансовому поведению

## 📋 Структура записей

Каждая запись содержит:
- 🏷️ **Категория** (зарплата, еда, транспорт и т.д.)
- 💰 **Сумма** (положительная для доходов, отрицательная для расходов)
- 📝 **Описание** операции
- 📅 **Дата** (игровая и реальная)
- 👤 **Возраст** игрока на момент операции
- 💳 **Баланс** после операции

## 🔧 Технические детали

### Автоматическое логирование
- **Все финансовые операции** автоматически логируются через `logIncome()` и `logExpense()`
- **Журнал ограничен** до 500 последних записей для оптимизации
- **Каждая запись** содержит уникальный ID и временную метку

### Экспорт данных
- **TXT формат** для максимальной совместимости
- **Полная информация** об игроке и статистике
- **Детальные записи** всех операций
- **Возможность поделиться** через любые приложения

### Интерфейс
- Кнопка журнала добавлена в основной интерфейс игры
- **RecyclerView** для эффективного отображения большого количества записей
- **Адаптивный дизайн** для разных размеров экрана
