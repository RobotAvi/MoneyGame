# 🎬 Руководство по анимации главного экрана

## 📋 Обзор

Главный экран приложения использует сложную многослойную анимацию для создания захватывающего пользовательского опыта.

## 🏗️ Архитектура анимации

### Слои (снизу вверх):
1. **OceanBackgroundView** - программный океанский фон
2. **LightEffectView** - круговой спектр света
3. **FrameLayout (coinsContainer)** - контейнер анимированных монет
4. **LinearLayout (mainContent)** - главное меню

### Временная последовательность:
```
0ms    → Океан появляется
200ms  → Начинается круговой спектр
600ms  → Монеты начинают всплывать
700ms  → Появляется меню
```

## 🪙 Система монет

### Параметры:
- **Количество**: 15 монет
- **Размеры**: 30-60 пикселей
- **Скорость**: 0.6-1.0 (множитель)
- **Задержка появления**: 0-4000ms

### Дизайн монет:
- **Форма**: круглая с золотым градиентом
- **Символ**: доллар ($) в центре
- **Цвета**: золотой градиент (#FFD700 → #FFA500 → #FF8C00)
- **Детали**: блики, тени, объемные эффекты
- **Фон**: полностью прозрачный

### Эффекты:
- **Эффект глубины**: маленькие монеты темнее (alpha 0.6-1.0)
- **Покачивание**: амплитуда 30px, частота 2Гц
- **Вращение**: 360° за время движения
- **Зацикливание**: бесконечное всплытие

### Распределение:
- **Сетка**: 5 колонок × 3 строки
- **Случайное смещение**: ±60% от размера ячейки
- **Перезапуск**: новая случайная позиция при достижении верха

## 🌊 Океанский фон

### Реализация:
- **Файл**: `ocean.jpg` (20KB) из папки Assets
- **Масштабирование**: centerCrop для полного покрытия экрана
- **Размещение**: в папке `res/drawable/`
- **Тип**: статичное изображение вместо программной отрисовки

## ✨ Световой эффект

### Компоненты:
- **Круговой спектр**: радиальный градиент от центра
- **Динамические лучи**: линейные градиенты (временно отключены)

### Оптимизации:
- **Минимальная прозрачность**: предотвращение перекрытия UI
- **Условное рисование**: только при alpha > 0
- **Без BlurMaskFilter**: для производительности

## 🎵 Звуковое сопровождение

### Музыка:
- **Файл**: `menu.mp3`
- **Зацикливание**: автоматическое
- **Громкость**: 50%
- **Управление**: автоматическое по жизненному циклу

## 🔧 Настройка параметров

### Основные константы:
```kotlin
// Длительности (мс)
OCEAN_ANIMATION_DURATION = 600L
LIGHT_SPECTRUM_DURATION = 800L
COINS_ANIMATION_DURATION = 1500L
MENU_ANIMATION_DURATION = 1000L

// Задержки (мс)
LIGHT_SPECTRUM_DELAY = 200L
COINS_START_DELAY = 600L
MENU_START_DELAY = 700L

// Параметры монет
COINS_COUNT = 15
COIN_MIN_SIZE = 30
COIN_MAX_SIZE = 60
COIN_MIN_SPEED = 0.6f
COIN_MAX_SPEED = 1.0f
```

## 🚀 Производительность

### Оптимизации:
- **Очистка памяти**: удаление анимаций при перезапуске монет
- **Условное обновление**: только при изменении параметров
- **Эффективные градиенты**: переиспользование объектов
- **Правильный жизненный цикл**: остановка при уходе с экрана

### Мониторинг:
- **Логирование**: подробные логи для отладки
- **Обработка ошибок**: try-catch блоки
- **Проверка состояния**: предотвращение утечек памяти

## 🐛 Отладка

### Частые проблемы:
1. **Монеты не видны**: проверить размеры контейнера
2. **Меню перекрывается**: проверить прозрачность света
3. **Анимация не запускается**: проверить жизненный цикл активности
4. **Утечки памяти**: проверить очистку ресурсов в onDestroy

### Логи для отладки:
```kotlin
Log.d(TAG, "Layout sizes - coinsContainer: ${coinsContainer.width}x${coinsContainer.height}")
Log.d(TAG, "Created ${coins.size} coins")
Log.d(TAG, "Animation sequence started")
```
