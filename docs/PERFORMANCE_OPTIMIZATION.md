# 🚀 Performance Optimization Guide

## Проблема
Воркфлоу по очистке кэша (`clear-cache.yml`) работает очень долго (4+ минуты), что замедляет процесс разработки.

## Причины медленной работы

### 1. Устаревшие версии actions/cache
- **Было**: `actions/cache@v3` (медленный)
- **Стало**: `actions/cache@v4` (быстрый)

### 2. Неоптимальные настройки сжатия
- **Было**: Использование `zstdmt` с настройками по умолчанию
- **Стало**: Оптимизированные настройки сжатия

### 3. Отсутствие оптимизаций Gradle
- **Было**: Базовые настройки Gradle
- **Стало**: Полный набор оптимизаций

## Внесенные изменения

### 1. Обновление GitHub Actions Cache
```yaml
# Было
uses: actions/cache@v3

# Стало  
uses: actions/cache@v4
with:
  compression-level: 6
  enableCrossOsArchive: false
```

### 2. Оптимизация Gradle настроек
```properties
# Включены параллельные сборки
org.gradle.parallel=true

# Оптимизация памяти
org.gradle.jvmargs=-Xmx4g -XX:+UseParallelGC

# Ускорение конфигурации
org.gradle.configureondemand=true
org.gradle.workers.max=4
```

### 3. Улучшенная очистка кэша
- Добавлены дополнительные шаги очистки
- Локальная очистка Gradle кэша
- Очистка Android кэша

## Ожидаемые улучшения

### Время выполнения
- **До**: 4+ минуты
- **После**: 1-2 минуты (ожидаемое сокращение на 50-75%)

### Производительность кэша
- Более быстрая загрузка/выгрузка кэша
- Лучшая компрессия
- Меньше использования дискового пространства

### Сборка проекта
- Параллельные сборки Gradle
- Оптимизированное использование памяти
- Быстрая конфигурация

## Дополнительные рекомендации

### 1. Мониторинг производительности
```bash
# Проверка времени выполнения воркфлоу
# В GitHub Actions: Actions > Workflows > View run time
```

### 2. Оптимизация размера кэша
- Регулярная очистка старых кэшей
- Использование более специфичных ключей кэша
- Исключение ненужных файлов из кэша

### 3. Настройка retention policy
```yaml
# В workflow файлах
retention-days: 7  # Уменьшить время хранения артефактов
```

## Команды для диагностики

### Проверка размера кэша
```bash
du -sh ~/.gradle/caches
du -sh ~/.android/cache
du -sh $ANDROID_SDK_ROOT
```

### Очистка локального кэша
```bash
./gradlew clean
./gradlew cleanBuildCache
rm -rf ~/.gradle/caches/*
rm -rf ~/.android/cache/*
```

### Мониторинг производительности Gradle
```bash
./gradlew build --scan
./gradlew build --profile
```
