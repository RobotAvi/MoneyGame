# Финансовый успех — Игра-симулятор финансовой жизни

🎮 Образовательная игра, которая помогает освоить принципы финансового планирования через интерактивный игровой процесс.

## 🚀 Быстрый старт

### Установка
```bash
git clone https://github.com/RobotAvi/FinancialSuccess.git
cd FinancialSuccess
./gradlew assembleDebug
```

### Требования
- Android 7.0 (API 24) или выше
- Минимум 100 МБ свободного места

## 🎯 О проекте

Игрок создаёт персонажа, выбирает профессию и мечту, управляет доходами, расходами, активами и пассивами, чтобы достичь финансовой свободы.

### Основные возможности
- ✅ Создание персонажа (возраст, образование, навыки, семья, цели)
- ✅ Система профессий с реальными расходами и налогами
- ✅ Инвестиции и активы (недвижимость, бизнес, акции, облигации, крипто)
- ✅ Семейные механики (брак, дети, семейные расходы)
- ✅ Профессиональные риски и здоровье, влияющие на зарплату и расходы
- ✅ Финансовый журнал с аналитикой и экспортом в TXT
- ✅ Ежемесячные операции: зарплата, пассивный доход, кредиты, сбережения
- ✅ Календарная модель времени (реальная дата старта, месяцы и дни)
- ✅ Сохранение прогресса из меню игры

## 🕹️ Как играть
1. Создайте персонажа: выберите профессию, мечту, возраст и параметры
2. Настройте цели и ставку сбережений
3. Бросайте кубик, покупайте активы, управляйте расходами и рисками
4. Достигните финансовой независимости (когда пассивный доход ≥ расходы)
